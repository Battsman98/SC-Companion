# Project instructions

- Before deploying or pushing any update that changes the Discord bot used by Peep or SC Companion, ask the user for confirmation. Continue asking before every Discord-bot deployment until the user explicitly revokes this instruction.
- Peep remains the private home-server, website OAuth, inventory identity, feedback, ticket-support, and administrative Discord application.
- SC Companion is the separate public-install Discord application. Do not replace Peep's Discord credentials or route website authentication/support through SC Companion unless the user explicitly changes this architecture.
